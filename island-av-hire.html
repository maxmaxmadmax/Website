What We’ll Ask You

Four things decide an island job.

    How far the gear travels once it lands.

  2. Power, or none

    What the venue has. None is fine.

  3. Access and timing

    When we can land, and when it has to be off.

  4. The wet plan

    What happens to an outdoor setup if the wind comes up.
